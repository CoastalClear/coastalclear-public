# Data

This folder contains some important reference data for running the application and understanding the rationale behind CoastalClear.

`locations/` contains PDF infographics of the main recreational parks along Singapore's coastline, where beach cleanups can be done by all members of public. Each discrete area within every park also has its own [GeoJSON](https://geojson.io) representation.

`insert.sql` contains sample data that might be useful for deploying the application in a test environment.

`nea-historical-flotsam.csv` contains [data](https://www.nea.gov.sg/docs/default-source/default-document-library/yearly-flotsam-data.pdf) published by the [NEA](https://www.nea.gov.sg) on the monthly weight of flotsam collected across public beaches and parks, from 2019-2021.
