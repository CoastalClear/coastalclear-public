# CoastalClear

CoastalClear is a web application intended to help volunteers organize beach cleanups more effectively. 

It has a few core features:

1. It provides a map view of cleanup locations and their relative cleanliness scores over different points in time, using historical data of trash collected as well as recent volunteer man-hours spent. Users can also see bookings that have been made by other parties to prevent clashes
<p align="center">
<img src="https://github.com/user-attachments/assets/e3f0582e-2043-4720-919d-690d0a178bb7" class="center" />
</p>

2. Users can make bookings for a particular location, indicating the duration and expected volunteer count
<p align="center">
<img src="https://github.com/user-attachments/assets/7a38a0cb-e509-4229-8429-039de313f455" />
</p>

3. Cleanup volunteers can then submit timely feedback on any particular points of note for a location, and optionally include images and latitude/longitude coordinates
<p align="center">
<img src="https://github.com/user-attachments/assets/44739634-e5fe-414e-aa3e-a8f234fe1869" height="800"/>
</p>

4. Once a cleanup is complete, users can log information like the amount of trash collected and volunteer turnout, which will in turn benefit future efforts
